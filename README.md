# Ocevia Lab

Marketing website for Ocevia Lab — a software engineering studio based in Sri Lanka.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Pages

- Home
- Services
- Projects (with detail pages)
- About
- Contact
